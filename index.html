How to use this page

A quick reference for the Maker → Checker → Approve workflows and the test login details of each Corp ID.

QUICK START

  1. Find the card for your Corp ID. The heading and the badges on the card tell you which workflow it is for.
  2. Find the row with your user ID and role.
  3. Click the small copy icon inside the field you need (User ID, Login password or Transaction password). It turns into a green tick when copied.
  4. Paste it into the application you are logging in to.

WHAT YOU SEE ON A CARD

  • FINANCIAL Corp ID used for financial transactions (Workflow 2, ₹1 – ₹25,00,000).
  • NON-FINANCIAL Corp ID used for non-financial requests (Workflow 1).
  • NON-FINANCIAL FINANCIAL Both badges: the Corp ID can be used for both kinds of workflow.
  • Maker starts a request. Checker reviews and approves it. Viewer can only view.
  • Director Partner Proprietor are the user groups used in the workflow stages.
  • — none — in the transaction password means that user has no transaction password.

THE TWO WORKFLOW CARDS

  • Every request starts with a Maker, then goes to Checker 1 and then Checker 2. Each checker gives 1 approval.
  • Workflow 1 · Non-financial and Workflow 2 · Financial show which user groups play each stage.

FOR ADMINS: CUSTOMIZE

  1. Click Customize.
  2. Pick a Corp ID (or New Corp ID), choose the Type (Financial, Non-financial, Financial + Non-financial or None), the Environment (DEV, SIT, UAT or SIT & UAT), add an optional Heading, then fill role, user ID and passwords and click Add user.
  3. To change the Type or Environment of an existing Corp ID, pick it in the Corp ID list, change the dropdown and click Update Type / Environment. A success pop-up confirms it.
  4. To remove something, use the red ✕ next to a user or Delete Corp ID in the list at the bottom.
  5. When you are done, click Download index.html and upload that file to Netlify so everyone sees the changes.

GOOD TO KNOW

  • Changes you make in Customize are visible only on your device until the downloaded file is uploaded to Netlify.
  • This page holds shared test credentials. Keep it private and never add real production passwords.
